# Asad Khurshid — Portfolio

A responsive, single-page portfolio website for Md Asad Khurshid. Built with plain HTML, CSS, and JavaScript, so it runs without a build step, package installs, or API keys.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. For example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

The site is ready for GitHub Pages. Put these files at the root of a GitHub repository, then open **Settings → Pages**, choose **Deploy from a branch**, and select the `main` branch and `/ (root)` folder. GitHub Pages will show the public site URL in the same settings panel after deployment.

## Customize

- Update project names, descriptions, and links in `index.html`.
- Adjust colors and layout in `style.css`.
- The mobile navigation and India-local clock are in `script.js`.
