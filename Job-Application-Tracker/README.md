# Trackr — Job Application Tracker

A clean, responsive job-search dashboard built with **HTML, CSS and vanilla JavaScript**. Track applications, manage interview progress and keep useful notes in one place.

## Features
- Add, edit and delete job applications
- Track Applied, Interview, Selected and Rejected stages
- Dashboard counts for applications, interviews, selected roles and pending applications
- Search by company, role or location
- Filter by status and sort by date or company
- Save data in browser Local Storage
- Responsive desktop, tablet and mobile layout
- Optional job-posting link and personal notes

## Run locally
1. Open the Job-Application-Tracker folder.
2. Open index.html in your browser.
3. No build tools or dependencies are required.

## Project files
- index.html — application structure
- style.css — responsive styling
- script.js — application logic and Local Storage

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript

## Data and privacy
Application data is stored locally in the browser on the device where the app is used. Clearing browser site data may remove saved applications. This project does not send application data to a server.
